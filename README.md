# 🌱 Agrinho 2026

✨ Projeto desenvolvido para o Concurso Agrinho.

## 🌾 Sobre o projeto
Este site foi criado com o objetivo de apresentar a importância da agricultura sustentável, mostrando a conexão entre o campo e a cidade.

## 💻 Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## 🌎 Tema
Agricultura sustentável e preservação ambiental.

## 🚜 Objetivo
Conscientizar sobre a importância do agronegócio, da preservação da natureza e do desenvolvimento sustentável.
